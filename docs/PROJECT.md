# Project

The purpose of this project is to interact with my personal workout app Hevy to create new functionalities.

## Examples
A few examples of things I'd like to do:
- Ask questions about my workout history
- Ask to modify my next workout based on other factors (e.g. mood, injury, other sports I'm doing, etc.)
- Ask to modify my overall routing based on other factors

## Approach
I will approach this project with the following steps:
1. Build local Cursor agents to interact with the Hevy API
  - ✅ This is done! It works with the MCP server installed at `.cursor/mcp.json`
2. I want to build a chatbot interface to interact with the agents
